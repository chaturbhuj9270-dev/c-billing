STEP 1: Get Android SHA-1 Certificate
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Run this command:
  cd android
  ./gradlew signingReport

Look for output like:
  SHA1: AB:CD:EF:12:34:56:78:90:AB:CD:EF:12:34:56:78:90:AB:CD:EF:12

Copy the SHA1 value (include colons)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 2: Add SHA-1 to Firebase Console
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to: https://console.firebase.google.com/
2. Select project: "c-billing"
3. Click: Project Settings (gear icon)
4. Select: Your apps → Android app (c_billing)
5. Scroll down: "SHA certificate fingerprints"
6. Click: "Add fingerprint"
7. Paste: The SHA1 value from Step 1
8. Click: "Save"
9. WAIT: 2-3 minutes for changes to propagate

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 3: Enable Phone Authentication
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to: https://console.firebase.google.com/
2. Select project: "c-billing"
3. Click: Build → Authentication
4. Click: Sign-in method
5. Click: "Phone" 
6. Toggle: Enable (switch to ON)
7. Click: "Save"
8. WAIT: 2-3 minutes for changes to propagate

   → Verify SHA-1 is exactly correct (with colons)
   → Check it appears in Firebase Console

❌ Getting "invalid-cert-hash"?
   → Your SHA-1 is not registered
   → Follow Step 2 again, make sure it's exactly correct

❌ Phone number not working?
